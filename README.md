# 术数应用

本地传统文化推演工具（原「小六壬时运」）：支持 **网页版** 与 **Android App**。打开即按当前时间起课，并可合参八字、梅花易数、奇门遁甲、高岛断易、手相辅助与杨公风水。

> 仅供文化研究与娱乐参考，不构成任何决策建议。

## Android 手机 / 平板（下载即用）

1. 打开 Releases 页面下载 APK：  
   **https://github.com/SimonDing/xiaoliuren-web/releases**
2. 在手机中允许「安装未知应用」
3. 安装 `xiaoliuren-*-android.apk` 后直接打开使用，**无需浏览器、无需联网即可起课**（字体 CDN 可选）

当前分发包：`release/xiaoliuren-1.3.0-android.apk`（术数应用 · 小孩起名），见 [Releases](https://github.com/SimonDing/xiaoliuren-web/releases/tag/v1.3.0)。

**历次修改细节：** 见 [CHANGELOG.md](./CHANGELOG.md)（各版本功能、APK、界面与命理模块变更逐条记录）。

详细安装说明见 [docs/ANDROID.md](./docs/ANDROID.md)。

### 电子风水罗盘与 AI（自备 Key）

1. 在「杨公风水」中定位或填写经纬度  
2. 点「开启罗盘」→ 允许运动/方向传感器 → 手机持平，顶部对准墙面或书桌拟朝方向  
3. 盘面按磁北显示二十四山；实时提示办公桌等摆放  
4. （可选）填写 OpenAI 兼容的 Base URL / API Key / 模型，点「AI 杨公细化」；Key 只存本机

## 功能

| 模块 | 说明 |
|------|------|
| **小六壬** | 按农历月、日、时辰起课；全方面断语，并含**寻失物**、**测谎话**专题 |
| **问事专题** | 寻失物（方位/远近/人事）与测谎话（真伪/可信度），专业+白话对照 |
| **高岛断易** | 以打开/刷新的即刻时间为种子三钱起卦（一爻动），与小六壬合参 |
| **八字细盘** | 可选输入阳历生辰，排出四柱、十神、喜用、大运 |
| **梅花易数** | 时间起卦，定体用、动爻、变卦 |
| **奇门遁甲** | 简化时盘，标出生门/开门等吉方 |
| **改运指引** | 风险识别 + 多系统方位投票 |
| **手相辅助** | 预测不确信时，按《手相全篇》主线勾选掌纹，掺盲派断事白话，并与时课合参 |
| **小孩起名** | 按生辰八字喜用五行补益，结合五格参考、音义与风格，推荐单名/双名 |
| **杨公风水** | 三合详盘（天地人三针、穿山七十二龙、透地六十龙、周天分金、二十八宿、先后天八卦）、经纬度坐向床位；可选自备 AI Key |

## 使用说明

### 小六壬

1. 打开页面后自动按当前公历时间起课，显示月上起日、日上起时的课象路径
2. 如需指定时间，可修改页面中的农历年月日时输入框（内部已对应转换）
3. 输出包含：格局名称（大安、留连、速喜、赤口、小吉、空亡）、吉凶判断、专业断语（事业/财运/感情/健康/出行/人际/学业）、寻失物方位线索、测谎话真伪度，以及宜忌事项与时运指数

### 高岛断易

1. 以打开或刷新的即刻时间（年月日时分秒毫秒）为随机种子，模拟三钱法起卦，通常一爻发动
2. 页面显示本卦、上下卦、动爻、变卦及吉凶
3. 输出卦辞、爻辞与高岛流断解，并与小六壬合参，给出「壬卦合参」结论（气场是否相顺、综合建议）

### 八字细盘

1. 在「八字细盘」模块中输入阳历生辰：年、月、日、时（0-23）、分、性别
2. 点击「排盘合参」后，系统按立春换年、节令换月规则，排出四柱（年月日时柱天干地支）
3. 输出十神配置、五行强弱、喜用神、大运起运岁数，并结合当日小六壬课象五行，给出事业/财运/感情/健康方面的贴身行动建议

### 梅花易数

1. 在「改运指引」面板中，系统默认按当前时间起卦（年月日时算上下卦、动爻、体用）
2. 自动定出本卦、互卦、变卦，标明体卦、用卦及动爻位置
3. 输出包括：体用生克判断、吉凶方位、具体改运行动步骤（结合梅花易数与奇门遁甲的综合投票）

### 奇门遁甲

1. 在「改运指引」面板中，时盘与梅花易数同时生成
2. 按节气、阳遁阴遁排出九宫格局，标示值符、值使、生门、开门等八门位置
3. 查看九宫中天干地支、八门九星配置，系统给出吉凶方位建议（如生门、开门为吉方），用于出行、办公、谈判等方位择选

### 手相辅助

1. 当对小六壬课象或测字结果不太确信时，点击「手相辅助」→「需要手相辅助」
2. 按实际情况勾选：所看之手（左/右）、手型（木型长掌/火型精神/土型厚方/金型利落/水型柔厚）、生命线/智慧线/感情线/事业线/婚姻线的具体形态，及特殊纹（M字纹/断掌/神秘十字等）
3. 输出依《手相全篇》三才脉络与盲派白话，逐项解释各主线含义（专业术语 + 大白话对照），并与当下时课合参，给出总体/性格/事业/财运/感情/健康/家庭方面的综合判断

### 小孩起名

1. 在「小孩起名」模块中填写实际表单字段：`姓氏`（如：王）、`性别`（男/女）、`出生年`、`月`、`日`、`时（0-23）`、`分`、`名长`（单字名/双字名）、`风格`（文雅书卷/刚健有力/柔美秀丽/福泽吉祥/自然清新）
2. 点击「按命理起名」，系统先排八字喜用五行，再从内置字库中筛选符合喜用、性别、风格的汉字组合
3. 输出推荐候选姓名（单名或双名），每个候选显示五格数理（天、人、地、外、总格）、吉数命中评分、字义解释、音律搭配说明及命理匹配度；可点「同步八字生辰」从上方八字细盘自动填入

### 杨公风水与 AI 细化

1. 阅读页面中的「杨公知识库」选项卡（峦头理气、室内布局原则等），了解基本术语
2. 点击「开启罗盘」按钮，允许设备的运动与方向传感器权限，将手机顶部水平对准想测的墙面或书桌边缘
3. 罗盘实时显示：周天度数、二十四山、地盘正针（定坐向，如门、床、书桌朝向）、人盘中针（消砂，背后靠山）、天盘缝针（纳水，面前开阔）、穿山七十二龙、透地六十龙、分金、二十八宿等读数，每层都有专业术语与大白话对照提示
4. （可选）在「AI 细化分析」区域填写 OpenAI 兼容的 `API Base URL`、`API Key`、`模型`，点「保存 Key 设置」后点「AI 杨公细化」，可获得更详细的格局分析与摆放建议；API Key 仅保存在本机浏览器/App 本地存储，不会上传服务器

### 电子风水罗盘

1. 与「杨公风水」共用同一罗盘界面，点「开启罗盘」即启动设备方向传感器
2. 将手机水平持握，顶部对准想测的方向（如书桌前沿、床头朝向、门的朝向），罗盘指针自动指向磁北
3. 配合上方杨公风水三盘读数，用于现场勘测室内或办公室的坐向、来气、纳水方位，辅助家具摆放与开运布局

## 网页版快速开始

```bash
git clone https://github.com/SimonDing/xiaoliuren-web.git
cd xiaoliuren-web
# Windows
start index.html
```

在线仓库：https://github.com/SimonDing/xiaoliuren-web

```
├── release/                # 可分发 APK
├── scripts/prepare-www.js  # 打包前同步静态资源
├── docs/ANDROID.md         # Android 安装与自建说明

```

## 自行编译 Android

需要 Node.js、JDK 21、Android SDK：

```bash
npm install
npm run build:web
npx cap sync android
cd android
./gradlew assembleDebug   # Windows: gradlew.bat assembleDebug
```

APK 输出：`android/app/build/outputs/apk/debug/app-debug.apk`
